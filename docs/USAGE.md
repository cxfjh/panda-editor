# CnLang 编程语言教程

## 简介

CnLang 是一门面向中文开发者的编程语言，文件后缀为 `.cn`。它使用中文关键字、中文标点和中文函数名，让开发者能够用母语编写程序。

## 快速开始

### 第一个程序

```cn
输出*（"你好，世界！"）
```

### 变量

```cn
姓名 = "张三"
年龄 = 25
身高 = 1.75
输出*（姓名，年龄，身高）
```

## 数据类型

### 数字

```cn
整数 = 10
负数 = -5
小数 = 3.14
输出*（整数 + 负数）
输出*（小数 * 2）
```

### 字符串

```cn
问候 = "你好"
名字 = '李四'
输出*（问候 + 名字）
输出*（"长度：" + 长度*（问候））
```

### 布尔值

```cn

是假 = 假
输出*（是真 且 是假）
输出*（是真 或 是假）
输出*（非 是真）
```

```cn

```

### 元组

### 集合

## 条件语句

### 如果...否则

```cn
年龄 = 20

如果 年龄 >= 18：
    输出*（"成年人"）
否则：
    输出*（"未成年人"）
```

### 多条件判断

```cn
分数 = 85

如果 分数 >= 90：
    输出*（"优秀"）
另如 分数 >= 80：
    输出*（"良好"）
另如 分数 >= 60：
    输出*（"及格"）
否则：
    输出*（"不及格"）
```

### 嵌套条件

```cn
年龄 = 25
有票 = 真

如果 年龄 >= 18：
    如果 有票：
        输出*（"可以入场"）
    否则：
        输出*（"需要购票"）
否则：
    输出*（"年龄不足"）
```
